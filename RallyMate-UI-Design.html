交付说明

这份设计稿可直接作为 SwiftUI 实现或 Figma 复刻的蓝本。下面是关键实现边界，避免后续偏离 PRD 的核心定位。

Watch 优先保证可读性运动中数字足够大，次级信息最多两行。实时反馈 2-3 秒自动消失，避免打球时打扰。
强度是相对值所有 UI 文案使用“力度 / 强度 / 轻中重”，不要出现 km/h、m/s 或真实球速暗示。
陪伴文案要像人话教练点评聚焦“下一场可以怎么做”，少给冷冰冰的统计描述。
设置双端同步佩戴手、实时反馈、疲劳、防伤、触觉强度在 Watch 和 iPhone 都应同步。
